El sitio responde por HTTP

Por qué este fixture no dispara su regla

La regla busca URLs internas con esquema http que sirvan contenido sin llevar al visitante a HTTPS. En modo filesystem no puede haberlas: el fetcher sabe qué fichero sirve cada ruta y reescribe la URL sobre la base del rastreo, que es https://fixture.local/. El enlace de abajo está escrito con http:// a propósito y el motor lo unifica con su forma segura.

Un enlace interno escrito por HTTP, que el motor unifica

Los tests unitarios cubren el 2xx por HTTP, el 301 de HTTP a HTTPS —que es lo correcto y no avisa—, el 301 de HTTP a HTTP —que sigue estando mal—, el 404 por HTTP y la URL externa.
